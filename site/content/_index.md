# config.anlu.me

Literate configuration for the tools I use day-to-day. Every `*.org` file
under `src/` is the source of truth; the actual runtime configs under
`~/.config/` are produced by [Emacs `org-babel` tangling][tangle], and
this static site is generated from the same `*.org` sources by
[`ox-hugo`][ox-hugo].

Browse the [Docs](/docs/) to read the configs as documentation.

[tangle]: https://orgmode.org/worg/org-contrib/babel/intro.html
[ox-hugo]: https://ox-hugo.scripter.co/
