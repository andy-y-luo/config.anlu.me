

### Commit style {#commit-style}

```markdown
## Commit style

All commit messages must follow [Conventional Commits](https://www.conventionalcommits.org/). Common types:

- =feat:= — a new feature
- =fix:= — a bug fix
- =chore:= — tooling, deps, or other non-functional change
- =docs:= — documentation only
- =refactor:= — code change that neither fixes a bug nor adds a feature
- =test:= — adding or correcting tests

Use a scope in parens for the affected module when relevant, e.g.
=feat(tmux): ...=. Keep the subject line short, imperative, and under
72 chars. Project-level =AGENTS.md= files may add or override types
(rare).

```
