* Pi

Literate configuration for [[https://github.com/earendil-works/pi-mono][Pi]]. Each module tangles to its target under =~/.config/pi/agent/=.

Pi is a minimal and extensible agent harness. I like the overall philosophy of starting with a lightweight base, then only adding and configuring whatever is necessary, instead of starting out in a batteries-included way (e.g. OpenCode, Claude Code).
